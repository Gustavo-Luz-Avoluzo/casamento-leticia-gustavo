# Site de casamento — Letícia & Gustavo

## Publicação gratuita recomendada: GitHub Pages

1. Crie um repositório público no GitHub, por exemplo `casamento-leticia-gustavo`.
2. Envie `index.html`, `script.js` e a pasta `assets`.
3. Vá em Settings → Pages.
4. Em Build and deployment, escolha `Deploy from a branch`.
5. Selecione `main` e `/ (root)`.
6. Salve. O GitHub fornecerá o endereço público do site.

## Antes de publicar
Abra `script.js` e altere:
const WHATSAPP = "5515999999999";

para o número que receberá as confirmações, no formato:
55 + DDD + número, sem espaços ou símbolos.

A versão atual usa o WhatsApp como backend gratuito para RSVP, portanto não exige banco de dados.
